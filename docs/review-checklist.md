# Review Checklist

## Architecture
- Is the class doing only one thing?
- Is domain logic isolated from infrastructure?
- Are interfaces and boundaries clear?

## Reliability
- Are null cases handled?
- Are external calls protected?
- Are errors explicit and useful?

## Maintainability
- Is naming clear?
- Is the method too long?
- Is there hidden coupling?

## Investing AI specific
- Is market data logic separated from business rules?
- Is risk calculation deterministic?
- Is recommendation logic explainable?
- Is AI orchestration separated from core financial logic?
